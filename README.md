# BizPulse CRM

BizPulse is a Customer Relationship Management (CRM) system designed to help businesses manage customers, leads, and sales activities efficiently.

## 🚀 Features

* Customer management
* Lead tracking
* Sales activity management
* Dashboard for analytics
* Secure user authentication
* Role-based access
* REST API backend
* Responsive frontend interface

## 🛠️ Tech Stack

Backend:

* Python
* FastAPI / Django (whatever you used)

Frontend:

* HTML
* CSS
* JavaScript

Database:

* MySQL 
## ⚙️ Installation

Clone the repository

```
git clone https://github.com/yourusername/BizPulse.git
```

Install dependencies

```
pip install -r backend/requirements.txt
```

Run the server

```
python main.py
```
